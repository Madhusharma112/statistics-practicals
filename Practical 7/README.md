# Practical 7: Statistical Analysis using Regression, ANOVA and Correlation

## Overview
This practical focuses on statistical analysis using the Teachers' Rating dataset to examine relationships between teaching evaluation scores, beauty scores, gender, and age groups.

## Dataset
- **Dataset:** Teachers' Rating
- **File:** `teachingratings.csv`

## Key Analysis Performed
1. **Regression with T-test:** Analyzed the effect of gender on teaching evaluation scores.
2. **Regression with ANOVA:** Examined differences in beauty scores across different age groups.
3. **Correlation Analysis:** Studied the relationship between beauty scores and teaching evaluation scores.

## Libraries Used
- Python
- Pandas
- NumPy
- Statsmodels
- SciPy
- Matplotlib

## Key Findings
- Gender has a statistically significant effect on teaching evaluation scores.
- Beauty scores differ significantly across age groups.
- Beauty score has a significant positive relationship with teaching evaluation score.

## Conclusion
The practical demonstrates how regression, ANOVA, and correlation techniques can be used to analyze relationships between different variables and draw meaningful statistical conclusions.
