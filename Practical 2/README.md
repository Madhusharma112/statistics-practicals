# Data Analysis and Visualization of Teaching Ratings Dataset

## Objective

To perform data analysis and visualization on the Teaching Ratings dataset using Python, Pandas, and Matplotlib.

## Dataset Description

The `ProfEvaltnsBeautyPublic.csv` dataset contains information about professors, including beauty scores, gender, tenure status, and other instructor-related attributes. It is used to perform descriptive statistical analysis and explore patterns in the data.

## Tools and Libraries

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Analysis Performed

### Dataset Overview and Basic Analysis

* Load the dataset and examine its structure.
* Display the first few rows and inspect the dataset dimensions.
* Check column names and data types.

### Descriptive Measures

* Calculate the mean, median, minimum, and maximum values for the relevant student-related variable, as specified in the practical.
* Generate descriptive statistics to summarize the numerical variables in the dataset.

### Beauty Score Distribution

* Create a histogram to visualize the distribution of professors' beauty scores.

### Average Beauty Score by Gender

* Group the data by gender.
* Calculate and compare the average beauty score for each gender.

### Percentage of Tenured Professors by Gender

* Analyze tenure status across genders.
* Calculate the percentage of tenured professors within each gender group.

## Project Files

* `Practical_5.ipynb` – Contains the Python code and data analysis.
* `ProfEvaltnsBeautyPublic.csv` – Dataset used for the practical.
* `README.md` – Documentation describing the practical and its objectives.

## Conclusion

This practical demonstrates the use of Pandas for data exploration, descriptive statistics, and group-based analysis. Matplotlib is used to visualize the distribution of beauty scores, while gender-based comparisons help summarize differences in beauty scores and tenure status.
