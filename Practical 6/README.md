# Practical 6

## Dataset
Teaching Ratings Dataset

## Objective
To perform statistical analysis on the Teaching Ratings dataset using Python and SciPy.

## Tools Used
- Python
- Pandas
- NumPy
- SciPy

## Statistical Analysis Performed

### Q1. T-Test
To determine whether gender affects teaching evaluation rates using an independent two-sample Welch's t-test.

### Q2. ANOVA
To determine whether beauty scores differ across different age groups.

### Q3. Chi-Square Test
To determine whether tenure is associated with gender.

### Q4. Correlation
To determine whether teaching evaluation score is correlated with beauty score using Pearson correlation.
