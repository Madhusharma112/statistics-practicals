
## Dataset
Teaching Ratings Dataset

## Objective
To perform data analysis and visualization using the Teaching Ratings dataset.

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed

### Q1. Duplicate Cases and Age Analysis
- Identify duplicate cases using professor ID.
- Calculate the number of observations.
- Calculate mean age and standard deviation.
- Analyze age statistics for unique instructors.

### Q2. Teaching Evaluation by Course Division
- Calculate average teaching evaluation for different course divisions.
- Visualize the average teaching evaluation using a bar chart.
