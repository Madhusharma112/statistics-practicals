# Practical 4: Data Analysis and Visualization of Teaching Ratings Dataset

## Objective

To perform data analysis and visualization on the Teaching Ratings dataset using Python, Pandas, and Matplotlib.

## Dataset Description

The `ProfEvaltnsBeautyPublic.csv` dataset contains information about professors, including their identification numbers, age, teaching evaluation scores, and course division. It is used to explore instructor characteristics and analyze teaching evaluation scores.

## Tools and Libraries

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Analysis Performed

### Duplicate Cases and Age Analysis

* Identify duplicate observations based on professor ID.
* Calculate the total number of observations in the dataset.
* Calculate the mean and standard deviation of age.
* Analyze age statistics for unique instructors after handling duplicate records.

### Teaching Evaluation by Course Division

* Calculate the average teaching evaluation score for each course division.
* Create a bar chart to visualize and compare average teaching evaluation scores across course divisions.

## Project Files

* `Practical_4.ipynb` – Contains the Python code and data analysis.
* `ProfEvaltnsBeautyPublic.csv` – Dataset used for the practical.
* `README.md` – Documentation describing the practical and its objectives.

## Conclusion

This practical demonstrates how Pandas can be used for data cleaning, duplicate detection, and descriptive statistical analysis. Matplotlib is used to visualize and compare average teaching evaluation scores across course divisions.
